# CYB2100 – Cyber Defense

Eksamensbesvarelse i **CYB2100 Cyber Defense** ved Høyskolen Kristiania, høsten 2025.

**Karakter: A**

## Innhold

Eksamen dekket blant annet:

- Phishing og MITRE ATT&CK
- Analyse av ondsinnede Office-dokumenter
- YARA og ClamAV
- SIEM, Splunk og Wazuh
- Bruk av Splunk mot botsv1: boss of the soc v1
- Analyse av nettverkstrafikk og logger
- Lateral movement og Command & Control
- NIS2 og sikkerhet i kritisk infrastruktur
- Volt Typhoon og TTP-analyse

## Eksamensbesvarelse

PDF-en inneholder hele den innleverte eksamensbesvarelsen med analyser, skjermbilder, kommandoer, SPL-søk og referanser.
Vi ble begrenset til 10 sider innlevering her, derfor ting ble litt squishet sammen (batman forklarer på slutten under referanselister).
